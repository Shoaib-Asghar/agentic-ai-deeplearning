# Module 1: Introduction to Agentic Workflows

## Overview
This module explores moving beyond single-shot prompting to multi-step, iterative execution.

## Key Concepts
- **Spectrum of Autonomy**: Fixed workflows vs. adaptive autonomous loops.
- **Task Decomposition**: Breaking high-level objectives into research, synthesis, and review steps.
- **Planner-Executor Pattern**: The foundational architecture for goal-oriented agents.
